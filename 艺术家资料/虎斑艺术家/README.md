# 虎斑艺术家 · 微信艺术家主页资料

以用户提供的艺术家形象为参考，保留橙黑虎斑、奶油白面颊、黑框眼镜、黑色额发、琥珀眼睛、酒红衬衫和口袋钢笔。头像与横幅统一采用深青绿背景与暖色光线。

| 用途 | 上传文件 | 尺寸 | 大小限制 |
| --- | --- | --- | --- |
| 艺术家头像 | [avatar-640.jpg](avatar-640.jpg) | 640×640 | ≤500 KB |
| 艺术家个人主页横幅 | [banner-750x400.jpg](banner-750x400.jpg) | 750×400 | ≤80 KB |

以上规格来自本次用户提供的截图；按 1 KB=1000 字节的较严格口径检查，实际字节数及 SHA-256 见 validation.json。两个文件均为不透明 JPEG，可直接选择对应文件上传。未代为修改账号资料或提交审核。

头像呈现托腮思考的近景，横幅呈现绘图桌前创作的场景；无文字、品牌标志、界面框或水印。人物与原参考一致，背景与创作场景为本次生成。

references/ 保存用户原图与规格截图，raw/ 保存两张生成原图，prompts/ 保存逐张提示词，provenance.json 保存来源。export.ps1 保持纵横比进行轻微居中裁切和缩放，并自动选用满足文件大小限制的 JPEG 质量，不拉伸人物。

在 Windows 重新导出到新目录：`pwsh -File export.ps1 -Destination rebuild`。
