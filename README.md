# Desktop Pet Studio

一个角色，两种作品。桌宠和聊天表情共用角色外观、性格和动作语言，分别维护各自的原图、动画、成品与发布材料。

| 角色 | 角色设定 | 桌宠 | 表情包 | 微信投稿 |
| --- | --- | --- | --- | --- |
| [林小鹰](林小鹰/README.md) | [灰白黏土猫头鹰](林小鹰/角色设定/README.md) | [图集、动作、视频](林小鹰/桌宠/README.md) | [2 张专辑](林小鹰/表情包/README.md) | [素材入口](林小鹰/表情包/微信投稿/README.md) |
| [林小羊](林小羊/README.md) | [暖色简笔画小羊](林小羊/角色设定/README.md) | [制作状态](林小羊/桌宠/README.md) | [8 张专辑](林小羊/表情包/README.md) | [素材入口](林小羊/表情包/微信投稿/README.md) |

```text
角色名/
├── README.md               角色索引
├── 角色设定/                形象母版、性格、设计探索
├── 桌宠/                   动作、图集、运行包、桌宠宣传视频
└── 表情包/
    ├── 专辑/01-专辑名/      源图、提示词、帧、已确认成品及验证
    ├── 账号资料/            艺术家或角色头像、面板图标、简介
    └── 微信投稿/素材/       按投稿字段汇总的本地导出
```

日常改图从「专辑」入手。要上传时，打开该角色的「微信投稿/素材」，选择对应专辑，按「上传顺序.tsv」填含义词。投稿目录由脚本从已确认成品生成，避免同一份素材在两个目录分别维护。新克隆可在仓库根目录运行：

```powershell
python -m pip install -r tools/requirements.txt
python tools/build_wechat_upload.py 林小鹰
python tools/build_wechat_upload.py 林小羊
```

新增角色时，先建立「角色设定」，再按需要加入桌宠或表情包。新增专辑在「表情包/专辑」下用「编号-专辑名」命名，保留 pack.json、原始素材及标准导出。新的平台发布格式可以各自建立投稿目录并从同一套成品导出。
