# Desktop Pet Studio

一个角色，两种作品。桌宠和聊天表情共用角色外观、性格和动作语言，分别维护各自的原图、动画、成品与发布材料。

**直接选图：**[林小羊成品库](林小羊/表情包/成品/README.md)（114 张静态、50 张动图） · [林小鹰成品库](林小鹰/表情包/成品/README.md)（40 张静态）。每张静态均有透明底、纯白底的 240／512 像素版本。动图与对应静态图使用相同编号和文案。

日常使用打开「成品」，改图进入「专辑」，上传进入「微信投稿/当前」。制作源文件只维护一份，成品与投稿包由脚本重建。新克隆在仓库根目录运行（图像导出需 Windows、PowerShell 7）：

```powershell
python -m pip install -r tools/requirements.txt
python tools/build_sticker_library.py 林小鹰
python tools/build_sticker_library.py 林小羊
python tools/build_wechat_upload.py 林小鹰
python tools/build_wechat_upload.py 林小羊
```

成品库和投稿目录是可重建产物，不重复纳入 Git。源图、序列帧、修订版标准导出、选帧配置和脚本保存在仓库。生成器拒绝覆盖现有目录；重建时用 --output-dir 指定新目录，核对后再归档旧版。

新增角色先建立「角色设定」，再按需加入桌宠或表情包。新增专辑沿用「编号-专辑名」，由 投稿.json 的 source_dir 选择当前修订版；有动图时补充静帧选择记录。
