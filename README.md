# Desktop Pet Studio

桌宠与角色表情的创作工程。每个角色使用独立目录，集中保存身份参考、生成原图、提示词、动画、表情专辑、宣传素材和验证记录。

## 林小鹰

[进入林小鹰角色档案](林小鹰/README.md)

林小鹰是沿用原「知核」桌宠形象的灰白黏土小猫头鹰。2026-11-24 起，原「知核」与「林小鹰」资产统一归入 `林小鹰/`，不再作为两个独立角色维护。

合并保留全部原始素材与历史记录。旧素材、视频、脚本和原归档元数据中的「知核」及 `zhihe` 是历史名称，未进行批量替换或重新渲染；原归档内的 `archive_root` 是制作时路径，当前位置以本页导航为准。

新增角色时建立新的同级角色目录；同一角色的新表情专辑放入对应角色目录，避免复制成另一套身份。私人参考素材继续遵守所在归档的忽略规则。
