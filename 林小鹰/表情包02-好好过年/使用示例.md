# 春节聊天使用示例

以下为设计用例，不是真实聊天记录或用户测试结果。表情接在哪句话后、发给谁，比单独看画面更重要。

| 收到的话或当前情况 | 可发的表情 | 建议补充 |
| --- | --- | --- |
| 家人问“什么时候回来？” | 回家过年 | “今晚出发，明天下午到。” |
| 亲友说“上车了” | 一路平安 | “到了发个消息。” |
| 已经抵达家里 | 到家啦 | “行李拿到了，放心。” |
| 家庭群安排采购 | 年货备齐 | “水果和糖果我买好了。” |
| 收到一条新春祝福 | 接福啦／同喜同喜 | 按熟悉程度回祝，不必连发两张 |
| 年夜饭准备就绪 | 开饭啦 | 需要时另说时间、地址 |
| 亲友晒年夜饭 | 年年有余 | “看起来真丰盛！” |
| 通用新春问候 | 新年快乐 | 补具体称呼，减少群发感 |
| 给长辈或老师拜年 | 给您拜年 | “外婆，新年好！” |
| 关心长辈亲友 | 身体健康 | 结合对方近况表达关心 |
| 向一个家庭祝福 | 阖家幸福 | “替我问叔叔阿姨好。” |
| 同事、商家互道吉祥 | 恭喜发财 | 可以搭配事业祝愿 |
| 和亲密朋友开玩笑讨彩头 | 红包拿来 | 仅双方都接受的玩笑，不催索 |
| 已经收到红包 | 谢谢红包 | 可再补回祝；不要评价金额 |
| 收到祝福、礼物或关心 | 心意收到 | “也祝你新年顺顺利利。” |
| 收到对方祝贺 | 同喜同喜 | 回祝喜事；不机械接所有消息 |
| 已约好去亲友家 | 来串门啦 | “我们两点到，方便吗？” |
| 自己招待亲友 | 吃好喝好 | 茶与水果表达热情，不劝酒 |
| 熟悉亲友继续夹菜添饭 | 真吃不下了 | “太好吃了，真的饱啦，谢谢！” |
| 熟人间暂时不想继续某话题 | 先过个好年 | 可补“这件事我们节后再聊” |
| 分享迎财神习俗 | 接财神 | 尊重对方习惯，不默认人人参与 |
| 对方实际复工、开店 | 开工大吉 | “新一年合作顺利。” |
| 元宵或家庭团聚 | 团团圆圆 | “今晚一起吃汤圆吗？” |
| 聚会结束分别 | 下次再聚 | “到家报个平安，下回再约。” |

## 试用时要验证的三个问题

1. 家庭群、同辈朋友、工作关系分别有哪些图“愿意发”，哪些“看着可爱但不会用”？
2. 去掉文字后，感谢、邀请、婉拒的动作是否仍容易区分？加回文字后，是否能在手机尺寸一眼读清？
3. “红包拿来”“先过个好年”是否被接收者理解成玩笑或暂停，而非催促、敷衍或生气？

当前已完成图文语义与深浅底检查。上述问题仍需真实使用者反馈，不能用创作者自己的理解代替。
