知核 · 25分钟制作记录 · 石心SX深色版

Python 3.10+，依赖 Pillow、imageio-ffmpeg。
Windows 默认使用 Microsoft YaHei 与 Bahnschrift；其他系统请替换字体路径。

安装依赖：
python -m pip install Pillow imageio-ffmpeg

渲染：
python render_social_dark.py --output output

仅检查分镜和封面：
python render_social_dark.py --output output --stills-only

输出为1080×1920、24fps、54秒H.264/AAC。
