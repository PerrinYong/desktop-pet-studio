# 林小鹰微信投稿

**[当前上传素材](当前/README.md)** · [全部成品与静态／动态浏览](../成品/README.md) · [历史导出](历史/)

2 套专辑、40 张静态主图。

- 主图、缩略图按序号对应，上传顺序.tsv 提供文案与含义词。
- 动态专辑的静态备选独立放在该专辑的「静态备选」中，包含透明主图、纯白主图、缩略图和顺序表；选择一种类型使用。
- 封面、横幅、图标、简介放在专辑根目录；角色头像及账号文案在当前/账号资料。
- 512 大图和静态／动态并排浏览在「成品」，制作过程在「专辑」。

新克隆在仓库根目录依次执行：

```powershell
python tools/build_sticker_library.py 林小鹰
python tools/build_wechat_upload.py 林小鹰
```

输出目录存在时脚本拒绝覆盖；重建用 --output-dir 指向新目录，投稿脚本用 --library-dir 选择对应成品库。[详细维护规则](../../../docs/目录与投稿素材.md)
