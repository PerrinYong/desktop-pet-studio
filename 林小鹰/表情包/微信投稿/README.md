# 林小鹰微信投稿

本机生成的素材在此目录的 **素材** 子目录，包含 2 张专辑，40 张静态主图。选择某个专辑后，依次使用：

1. **主图/** 与 **缩略图/**：文件名前缀一一对应，顺序按「上传顺序.tsv」。
2. **cover-240.png、banner-750x400.jpg、icon-50.png**：分别填写专辑封面、详情横幅和聊天面板图标。
3. **专辑资料.txt、上传顺序.tsv**：复制名称、简介和逐张含义词。
4. **素材/账号资料/**：角色头像、通用图标和账号文案。

新克隆时在仓库根目录运行 `python tools/build_wechat_upload.py 林小鹰`。依赖安装、重建方式及目录对照见[目录与投稿素材](../../../docs/目录与投稿素材.md)。
