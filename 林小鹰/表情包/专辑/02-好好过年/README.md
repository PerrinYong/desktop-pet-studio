# 林小鹰 · 好好过年

24 枚春节静态表情。沿用灰白黏土猫头鹰，以朱红小马甲与暖金细节增加年味；覆盖从返乡、团圆到拜年、红包、访亲、开工和元宵的聊天。

## 创作定位

账号角色名仍为「林小鹰」。专辑名称建议：**林小鹰好好过年**。

专辑简介：**回家报平安，拜年说吉祥，红包认真谢，饭局轻松接。让林小鹰陪你把这个年过得暖一点。**

不绑定生肖年份。敬意、感谢、玩笑和婉拒分别设计，按对象使用；亲近关系里的玩笑不直接推广到所有工作或长辈关系。

## 文件与复现

本目录保留参考、生成原图、完整提示词、独立成品和检查记录。`scripts/export.ps1` 执行等比缩放、透明留边与预览排版，不重绘角色和文字。新增输出目录重建：

```powershell
pwsh -File scripts/export.ps1 -OutputRoot rebuild
pwsh -File scripts/export-support.ps1 -OutputRoot rebuild
```

成品为静态 PNG，没有动态 GIF。规格以此前用户提供的表单为制作依据，投稿前须复核当前平台要求。PNG 尺寸、透明度、字节数及哈希由本地检查确认；尚未进行微信客户端发送测试、投稿审核或实际复用测量。
