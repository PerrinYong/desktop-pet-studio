# 林小羊 · 今晚有安排

16 张原创静态表情，用于商务 KTV、台球馆、足浴门店的营业招呼、熟客邀约、订位与到店接待。沿用林小羊的卷角、垂耳、简笔轮廓，增加深青色领结和预约道具。熟客款保留一点主动营业的自嘲，确认信息用清晰、礼貌的短句。

「客户雷达启动」适合朋友圈或熟客群的暖场。留位、空位和改期表情配合正文写清时间、人数、房型及保留期限等实际信息。「发您定位」搭配真实的地图卡片。

参考案例保存在私有项目笔记。借鉴放大文案、道具反差和给熟客递话的方法，以原创羊形象和简化道具重新演绎。四张用户参考图单独管理。

制作使用内置 image_gen 独立生成透明角色、独立封面和横幅原图。文字通过 System.Drawing 按最终字句排版；120 像素缩略图使用无字构图。[生成原图](raw/) · [提示词](prompts/) · [逐张语义清单](pack.json) · [生成记录](provenance.json) · [本地验证](validation.json)。

从当前目录重建图片时，请给脚本指定一个新的输出目录：

```powershell
pwsh -File scripts/export.ps1 -OutputRoot rebuild
```

如果已有透明成品，只补导纯白底可运行 `pwsh -File scripts/export-white.ps1`。
