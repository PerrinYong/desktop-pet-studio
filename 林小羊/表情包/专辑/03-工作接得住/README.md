# 林小羊 · 工作接得住

8 张静态表情。适用对象：同事、项目协作群。设计定位：把确认、处理、对齐与交接说清楚，表情之外补充时间和事实。

## 场景与用法

| 编号 | 文案 | 含义词 | 触发场景 | 使用说明 |
| --- | --- | --- | --- | --- |
| 01 | 收到 | 确认 | 确认收到信息 | 仅确认收到，不等于已承接或完成 |
| 02 | 我看一下 | 查看 | 初步检查 | 说明开始查看，必要时补反馈时间 |
| 03 | 处理中 | 处理 | 告知处理状态 | 正在处理；关键事项另补预计完成时间 |
| 04 | 对齐一下 | 对齐 | 核对目标与理解 | 正文说清要对齐的目标、范围或口径 |
| 05 | 辛苦确认 | 确认 | 请对方确认结果 | 正文带上具体对象、链接和确认事项 |
| 06 | 联调中 | 联调 | 跨端接口联调 | 实际进入联调时使用，正文补环境、接口和阻塞项 |
| 07 | 已同步 | 同步 | 完成信息同步 | 仅在确已发送或更新后使用，不等于对方看过 |
| 08 | 可以提测 | 提测 | 研发交接测试 | 达到约定提测条件后使用，附版本、范围与已知问题；不等于测试通过 |

## 角色与制作

沿用原始参考 [林小羊母版](references/character-master.png)：卷角、侧垂耳、奶油白羊毛、点状眼睛和小黑蹄。动作围绕可压扁、可拉长的羊毛身体展开。工作回应保持注意力；同事自嘲与熟人玩梗允许更强的变形。

内置 image_gen 逐张生成，保留 [原图](raw/)、[提示词](prompts/)、[语义清单](pack.json)、[含义词](含义词.txt)及 [生成来源](provenance.json)。导出脚本只负责等比缩放、透明留边与排版。

```powershell
pwsh -File scripts/export.ps1 -OutputRoot rebuild
```

[技术检查](validation.json)记录尺寸、alpha、字节数和哈希。当前为制作交付，未进行微信实发、商店审核和真实复用测量。[四套设计依据与区别](../../场景扩展说明.md)说明来源与语气选择。
