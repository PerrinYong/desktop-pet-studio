## 构图做法

短语按含义拆成自然的阅读单元，围绕人物脸部、手势和道具安排。重点词可以变大，但不遮挡表情；对话框的尾部指向说话者，文字沿动作方向排布，卡片上的字就是角色正在表达的信息。每张单独构图，不套统一的底部字幕模板。

保留林小羊的奶白羊毛、卷角、松弛的眉眼和青绿领结。常规聊天尺寸 240 像素下仍要读得清字；纯白底与透明底来自同一构图。

## 动画制作

每张重新生成一幅带文字的 2×2 四姿态图，再按共同裁剪范围映射到 240×240；不为每帧单独缩放，以减少大小抖动。沿用各表情的 16 帧节奏，10 fps、1.6 秒循环。文字保留在同一构图区域，随手绘姿态有轻微变化，不额外施加全图抖动。

[四姿态总览](preview/序列帧总览-深底.png)和[逐帧素材](animation/frames)均保留。03 与 06 的首轮图出现白底或分格线，已通过图像编辑重新生成透明版本；首轮原图、修正原图和修正提示词都在 raw、prompts 中，pack.json 的 sheet 字段指定实际采用版本。

## 文件与复现

raw 保存模型原始输出，prompts 保存逐张提示词，pack.json 保存文案与含义，provenance.json 保存来源和 SHA256。导出脚本只做裁切、尺寸适配、白底合成和编码，不再叠加独立字幕。

在仓库根目录运行：

```powershell
pwsh -NoProfile -File tools/export_integrated_business.ps1 -Album '12-有事您招呼' -FFmpeg '你的 ffmpeg.exe 绝对路径'
python tools/validate_integrated_business.py
```

验证覆盖尺寸、透明度、外边缘、白底一致性、来源哈希、GIF 逐帧透明遮罩及循环时长。文字与构图另经深浅底总览人工目视检查。
