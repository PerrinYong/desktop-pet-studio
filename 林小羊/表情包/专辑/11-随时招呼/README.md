# 林小羊 · 随时招呼

16 张静态表情。面向商务联系人和熟客的日常沟通，覆盖问候、回访、邀约、确认、回应、指引、等候、体谅与收尾。文案、道具、封面与简介均不点明具体行业；同一句话可自然放进不同聊天上下文。

## 文案与含义词

| 编号 | 文案 | 含义词 | 沟通用途 |
| --- | --- | --- | --- |
| 01 | 随时在线 | 在线 | 告诉对方现在方便联系 |
| 02 | 老板好 | 问候 | 轻松礼貌地打招呼 |
| 03 | 好久不见 | 回访 | 熟客重启聊天 |
| 04 | 最近忙啥 | 关心 | 熟人之间轻松问近况 |
| 05 | 今晚有空吗 | 邀约 | 向熟客发出开放式邀约 |
| 06 | 您看几点 | 约时间 | 把时间选择权交给对方 |
| 07 | 几位一起 | 问人数 | 确认同行人数 |
| 08 | 收到收到 | 收到 | 接收并回应信息 |
| 09 | 马上安排 | 安排 | 开始办理对方请求 |
| 10 | 给您留着 | 预留 | 确认已经预留 |
| 11 | 发您定位 | 定位 | 配合地图位置发送 |
| 12 | 到了喊我 | 接应 | 约定碰面时联系 |
| 13 | 不急慢慢来 | 不催 | 安抚对方不用赶时间 |
| 14 | 改天也行 | 改期 | 接受改期给对方台阶 |
| 15 | 谢谢照顾 | 感谢 | 表达被支持的感谢 |
| 16 | 下次再约 | 再约 | 自然收尾并留下下次联系空间 |

“老板好”是轻松的敬称；“最近忙啥”“今晚有空吗”更适合已有交流基础的联系人。时间、人数、位置等实际信息另用文字补充。“给您留着”应在确认预留后发送；“改天也行”用于接受改期，避免连续追问。

## 设计与制作

保持林小羊的奶油羊毛、燕麦肤色、双螺旋羊角、下垂耳朵、粗炭黑轮廓和青绿色领结。用独立动作与表情区分意图，少量手机、手表、定位符号只承担通用沟通含义。温和、略带自嘲的神态让邀约、等待与拒绝更容易接住。

全部主图、专辑封面和横幅使用内置 image_gen 分别生成；原图在 raw，逐图完整提示词在 prompts，来源与哈希在 provenance.json。字符由 System.Drawing 统一排版，避免生成文字出错；缩放保持比例，保留原生透明通道，纯白底由对应透明图直接合成，不再独立重画。生成方法沿用上一专辑的导出脚本。

复现：运行 scripts/export.ps1 -OutputRoot <尚不存在的新目录>，会输出两种背景、两种主图尺寸、缩略图、专辑配套和总览。需要重建微信投稿目录时，在仓库根目录运行 python tools/build_wechat_upload.py 林小羊 --output-dir <尚不存在的新目录>。

检查记录见 validation.json。尺寸与透明通道验证不等同于平台审核；尚未上传发布。
