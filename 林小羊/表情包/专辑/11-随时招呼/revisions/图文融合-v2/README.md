## 构图做法

短语按含义拆成自然的阅读单元，围绕人物脸部、手势和道具安排。重点词可以变大，但不遮挡表情；对话框的尾部指向说话者，文字沿动作方向排布，卡片上的字就是角色正在表达的信息。每张单独构图，不套统一的底部字幕模板。

保留林小羊的奶白羊毛、卷角、松弛的眉眼和青绿领结。常规聊天尺寸 240 像素下仍要读得清字；纯白底与透明底来自同一构图。

## 文件与复现

raw 保存模型原始输出，prompts 保存逐张提示词，pack.json 保存文案与含义，provenance.json 保存来源和 SHA256。导出脚本只做裁切、尺寸适配、白底合成和编码，不再叠加独立字幕。

在仓库根目录运行：

```powershell
pwsh -NoProfile -File tools/export_integrated_business.ps1 -Album '11-随时招呼'
python tools/validate_integrated_business.py
```

验证覆盖尺寸、透明度、外边缘、白底一致性、来源哈希。文字与构图另经深浅底总览人工目视检查。
