# 林小羊 · 年会轮到我

8 张静态表情。适用对象：同事年会群、熟悉同事私聊。设计定位：同时容纳期待、参与、紧张和体面收尾，表演和喝酒保留选择。

## 场景与用法

| 编号 | 文案 | 含义词 | 触发场景 | 使用说明 |
| --- | --- | --- | --- | --- |
| 01 | 排练中 | 排练 | 准备年会节目 | 自愿参与时分享状态 |
| 02 | 怎么是我 | 紧张 | 被叫上台 | 表达紧张，避免把同事画成恶意角色 |
| 03 | 我负责鼓掌 | 参与 | 在台下支持节目 | 提供无需表演的参与方式 |
| 04 | 坐等抽奖 | 期待 | 等抽奖环节 | 真实期待与玩笑，不承诺中奖 |
| 05 | 这次到我 | 中奖 | 中奖或期待叫号 | 用实际上下文区分期待与已中奖 |
| 06 | 重在参与 | 自嘲 | 没抽中后自我安慰 | 保留体面，不嘲笑别人的奖品 |
| 07 | 我先开吃 | 吃席 | 聚餐开席 | 等主持或同桌确认开席后使用 |
| 08 | 今晚辛苦啦 | 感谢 | 活动散场 | 感谢组织、后勤或表演者的付出 |

## 角色与制作

沿用原始参考 [林小羊母版](references/character-master.png)：卷角、侧垂耳、奶油白羊毛、点状眼睛和小黑蹄。动作围绕可压扁、可拉长的羊毛身体展开。工作回应保持注意力；同事自嘲与熟人玩梗允许更强的变形。

内置 image_gen 逐张生成，保留 [原图](raw/)、[提示词](prompts/)、[语义清单](pack.json)、[含义词](含义词.txt)及 [生成来源](provenance.json)。导出脚本只负责等比缩放、透明留边与排版。

```powershell
pwsh -File scripts/export.ps1 -OutputRoot rebuild
```
