# 林小羊

一只容易瘪下去、仍愿意伸出小蹄子回应别人的羊。以柔软身体的压扁与鼓起承载疲惫、回应和突然开心。

- [形象探索 01：羊年慢慢来](形象探索01-慢半拍过年/README.md)：角色母版、8 张静态样张、24 张场景方案、研究依据和过程资产。当前为首轮方向，非正式定稿。

角色与林小鹰分目录保存；本轮采用独立的简笔画风格。
