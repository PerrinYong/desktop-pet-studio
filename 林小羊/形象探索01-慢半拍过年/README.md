# 林小羊：羊年慢慢来

状态：角色方向初稿，已制作角色母版与 8 张独立静态样张；24 张场景方案已编排，剩余 16 张未生成。设计日期：2026-11-25。

## 一句话认识它

**已经瘪了，但还愿意回你一句。**

林小羊是一只慢半拍、容易累、仍愿意与人连接的小羊。它可以不精神、不完美，也可以高兴得突然支棱。核心不是把“摆烂”当人设，而是让使用者不必先表现得体面、积极、会说话，才能参与聊天。

专辑暂名：**林小羊·羊年慢慢来**。简介草案：**有点瘪，心意没瘪。林小羊陪你慢慢过年，好好接话。**

## 角色与行为

- **轮廓**：一团可压扁、可鼓起的羊毛身体；少量大弧线，不画细密毛丝。
- **身份**：奶油白羊毛、燕麦色脸与卷角、侧垂长耳、小黑蹄、点状眼睛。与林小鹰共享温暖气质，使用独立的简笔画语言。
- **常态**：身体松垮，眼睛还有回应，伸一只蹄子表示“我在”。不固定阴沉、嘲讽或讨好的微笑。
- **情绪幅度**：缓缓时像软垫，回礼时勉强撑起一点，开心时突然拉长、弹起来。辨识度来自重复的行为模式。
- **春节层**：只在需要时加入围巾、红包、行李或食物；平时没有固定节日服装，节后也可用。
- **文字**：短、口语、能接话；羊谐音少量使用。“咩问题”有用时才出现，不把每个动词都改成“咩”。

## 把用户反馈落实成设计标准

| 核心需求 | 本次做法 | 检查方式 |
| --- | --- | --- |
| 不必表演精致、精神饱满 | 允许瘫软、停顿、短句回应 | 看到图会不会觉得“这就是我现在” |
| 降低发送与回复的压力 | 不催红包、不强迫振作、不索要安慰；感谢后可自然结束 | 接收者是否觉得必须继续哄它或回长文 |
| 崩坏时被理解 | 用自己的身体状态作轻微自嘲，不攻击他人 | 能否表达疲惫，又不把对方推开 |
| 容易记住并形成共鸣 | “瘪下去但伸出一只蹄子”的行为反复出现 | 去掉文字是否仍认得、能读懂大致状态 |
| 保留真实情绪差异 | 感谢、兴奋、休息、邀请分别画不同重心 | 缩小后是否只是同一个头像换道具 |

这次选择简笔画，是因为身体变形和停顿感更突出。低清、拼接、破损并非必需，也不天然等于“有网感”。同样的性格可以做精致版本，但精致不能挤掉可借用的语气。当前风格是一条测试路线，不是对其他路线的否定。

“慢慢来”仍有语境：对方遇到紧急问题时，应给实际回应；表情不能代替帮助。对长辈、客户等关系保留清楚、无反讽的问候。

## 首批 8 张：先检验角色能否接话

| 编号 | 文案 | 使用机会 | 情绪与动作 |
| --- | --- | --- | --- |
| 01 | 羊年好呀 | 向朋友主动拜年 | 轻松问候，不要求对方回一整段祝词 |
| 02 | 到家就躺 | 抵达后给亲友报平安 | 应补具体地点；用疲惫姿态释放表演精神饱满的压力 |
| 03 | 心意收到 | 回应祝福、红包或关心 | 图中用爱心而非金钱，适用范围更广 |
| 04 | 我先缓缓 | 聚会疲惫或暂时暂停回复 | 告诉对方自己的状态，不把冷淡归咎给对方 |
| 05 | 慢慢来 | 接住对方的着急或疲惫 | 与行动建议配合，不能用来敷衍紧急求助 |
| 06 | 突然精神 | 收到红包、好消息或开饭通知 | 朋友间表现开心；不把感谢限定为红包金额 |
| 07 | 吃不动了 | 年夜饭或聚餐婉拒添饭 | 感谢招待后表达饱足，不羞辱体型 |
| 08 | 咩问题 | 答应帮忙或接住普通请求 | 轻量承诺，办不到时不拿它敷衍 |

## 使用与验证

[240 像素样张](exports/wechat-240/)用于手机小尺寸试发；[512 像素图](exports/chat-512/)用于通用聊天展示；[120 像素图](exports/thumbnails-120/)用于缩略预览。[含义词](含义词.txt)可用于整理上传字段。

建议先把“我先缓缓”“心意收到”“慢慢来”放进真实熟人聊天：对方是否能感受到回应，而非被敷衍？再测试“突然精神”的反差是否有趣。如果只有创作者觉得可爱、使用者不知道何时发，就先改文案和动作，不加更多装饰。

目前为创作与本地视觉检查，不代表微信审核通过、实际传播效果或用户偏好已经得到验证。本阶段未制作正式专辑横幅与账号资料，以便角色方向调整时不重复制作。
