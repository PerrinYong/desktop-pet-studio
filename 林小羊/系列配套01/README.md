# 林小羊系列配套

制作日期：2026-11-25。角色资料和 8 张场景专辑的封面、图标、横幅与文案，沿用用户提供的微信素材规格。此处是制作档案；可用素材同时放在各专辑的 assets 目录。

## 形象资料

名称：**林小羊**

简介：**有点瘪，心意没瘪。林小羊陪你接住日常的小情绪，慢慢来，也好好回应。**

一团能瘪下去、也能鼓起来的奶油白羊毛身体；燕麦色脸、双卷角、侧垂耳、点状眼睛和小黑蹄构成辨识度。动作可以疲惫，态度仍有回应。整体是暖色简笔画，不固定节日服装，保持全年可用。情侣专辑中另一只小羊用鼠尾草绿围巾区分，不另设角色名称或性别。

## 配套规格与用途

| 素材 | 导出规格 | 用途 |
| --- | --- | --- |
| 形象头像 | PNG，240×240，透明 | 长期角色身份，独立于场景专辑 |
| 专辑头像／封面 | PNG，240×240，透明 | 专辑代表图；本次这两个称呼使用同一文件 |
| 聊天面板图标 | PNG，50×50，透明 | 进入对应专辑的小图标，由专辑封面等比缩小 |
| 专辑详情横幅 | JPG，750×400，不透明 | 无文字、有故事场景、非白背景 |
| 名称与简介 | UTF-8 文本 | 复制到对应资料字段 |

所有上传图目标小于 500KB。封面保留半身或全身，简洁、无文字、不添加白色外描边；横幅用彩色场景讲故事。图标不加细小文案。头像、图标按用户提供的“每半年只能修改一次”提示制作稳定版本；此处不操作线上账号。规格以本次用户截图为依据，未声称已核对平台最新规则。

## 制作与复现

使用内置 image_gen 分别生成 1 张形象头像、8 张封面、8 张横幅，共 17 张独立原图。角色参考为 [母版](references/character-master.png)。[提示词](prompts/)逐张保存；[plan.json](plan.json)记录场景、文案与画面设计，[provenance.json](provenance.json)记录生成来源。

导出使用 PowerShell / System.Drawing，仅进行透明边界裁切、等比缩放和横幅居中裁切，不重绘角色。原图保留，旧专辑主体与动画不修改。

```powershell
pwsh -File scripts/export.ps1 -OutputRoot rebuild
pwsh -File scripts/preview.ps1 -AssetsRoot rebuild -PreviewRoot preview-rebuild
```

[技术验证](validation.json)检查尺寸、格式、透明度、体积、哈希和清单；[视觉检查](visual-review.json)记录深浅底、小尺寸与场景检查。微信客户端实测、投稿与审核未执行。
