# 目录与投稿素材

## 文件放在哪里

- 通用的角色参考、外观、性格与早期探索放「角色设定」。已有制作过程里的参考快照随该项目归档。
- 桌宠动作、图集、运行包和桌宠宣传视频放「桌宠」。林小鹰原「知核」归档整体迁移，保留归档内部布局。
- 表情角色主页素材放「表情包/账号资料」。专辑的原图、脚本、帧、图标、封面与横幅放「表情包/专辑」。林小羊跨专辑生成过程放「表情包/制作配套」。
- 微信上传使用「表情包/微信投稿/素材」。此目录是生成产物，改图与改文案通过来源目录维护，再生成到新目录。

## 生成和维护投稿素材

在仓库根目录安装 [Pillow 依赖](../tools/requirements.txt)，运行 [投稿整理脚本](../tools/build_wechat_upload.py)：

```powershell
python -m pip install -r tools/requirements.txt
python tools/build_wechat_upload.py 林小羊
python tools/build_wechat_upload.py 林小鹰
```

首次默认输出到各自的「表情包/微信投稿/素材」。重新生成时可以传入 `--output-dir` 指向一个新目录，便于比对版本。生成目录默认由 Git 忽略，仓库保存可重建的源文件和脚本。

脚本按 pack.json 顺序组装专辑。静态图复制既有主图和缩略图；动态主图原样保留，缩略图取循环中间一帧缩为 120×120。缺少发布字段或有不同来源路径时，在该专辑用投稿.json 补充。含义词、主图和缩略图共用编号。账号资料和专辑资料分别打包。

软件按现有交付规格检查格式、尺寸、字节数、透明度和循环属性。实际上架前以平台后台规则为准，并按要求填写 AI 声明、权属等字段。
